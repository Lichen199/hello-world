# 像素风机甲对战游戏 - 产品需求文档

## 1. 产品概述

一款复古像素风格的2D机甲对战小游戏，两名玩家各自操控一台机甲进行战斗。游戏采用经典的街机格斗模式，支持移动、攻击、防御等基本操作，通过消耗对手血量决出胜负。目标用户为怀旧游戏爱好者和休闲玩家。

核心卖点：
- 纯像素风格画面，致敬80年代街机游戏
- 简洁直观的操控体验
- 充满机械美感的机甲设计

## 2. 核心功能

### 2.1 游戏角色

| 机甲名称 | 外观特点 | 基础属性 |
|---------|---------|---------|
| 红狼机甲（Red Wolf） | 红色系、尖刺装甲、热血风格 | 攻击型：高攻击、中等防御 |
| 蓝鹰机甲（Blue Eagle） | 蓝色系、流线型、冷静风格 | 防御型：中等攻击、高防御 |

### 2.2 操作指令

#### 玩家1（红色方）- 键盘WASD
- W: 跳跃
- A: 向左移动
- S: 下蹲/防御
- D: 向右移动
- J: 轻攻击
- K: 重攻击

#### 玩家2（蓝色方）- 方向键
- ↑: 跳跃
- ←: 向左移动
- ↓: 下蹲/防御
- →: 向右移动
- 1: 轻攻击
- 2: 重攻击

### 2.3 游戏机制

#### 血量系统
- 每台机甲初始血量：100点
- 血量显示在屏幕上方，以像素风格血条呈现
- 血量归零判定为失败

#### 攻击系统
- **轻攻击**：快速出拳，伤害10点，冷却0.3秒
- **重攻击**：重拳挥砍，伤害25点，冷却1秒
- 攻击命中时产生像素粒子特效

#### 防御系统
- 按住防御键可减少50%受到的伤害
- 防御状态下角色呈半透明状
- 防御不能完全抵挡重攻击

#### 胜负判定
- 当任意一方血量归零时游戏结束
- 胜利方显示胜利动画和结算界面
- 提供重新开始按钮

### 2.4 场景设计

- **战场背景**：废弃的工业区工厂，暗色调工业风
- **地面平台**：金属质感的工业地板，带有磨损纹理
- **装饰元素**：背景中的烟囱、管道、警示标识
- **光效**：顶部工业灯光，地面反光效果

## 3. 用户界面设计

### 3.1 整体视觉风格

- **像素密度**：16x16像素基础单元
- **调色板**：复古16色调色板，以深蓝、暗红、金属灰为主
- **动画帧率**：每秒8帧，呈现流畅的像素动画
- **屏幕效果**：轻微的CRT扫描线效果

### 3.2 界面布局

```
+------------------------------------------+
|  [红狼HP条]        VS        [蓝鹰HP条]   |
+------------------------------------------+
|                                          |
|         [游戏主战场 - 像素场景]            |
|                                          |
|    [机甲A]                      [机甲B]   |
|                                          |
|==========================================|
|            [金属地板]                     |
+------------------------------------------+
|  P1控制      [状态信息]        P2控制    |
+------------------------------------------+
```

### 3.3 开始界面

- 像素风格标题"MECHA BATTLE"
- "PRESS START" 闪烁提示
- 机甲展示动画
- 控制说明面板

### 3.4 胜负界面

- 胜利机甲的胜利动画（高举双臂）
- "WINNER!" 像素文字特效
- 重新开始按钮

## 4. 角色动画帧

### 4.1 红狼机甲动画

- **待机**：4帧循环，微微起伏
- **行走**：6帧循环，腿部交替
- **跳跃**：2帧（起跳、空中）
- **攻击**：3帧（准备、挥拳、收拳）
- **防御**：1帧（双臂交叉）
- **受击**：2帧（后退、恢复）
- **胜利**：4帧循环（高举双臂庆祝）

### 4.2 蓝鹰机甲动画

- **待机**：4帧循环，微微起伏
- **行走**：6帧循环，腿部交替
- **跳跃**：2帧（起跳、空中）
- **攻击**：3帧（准备、挥拳、收拳）
- **防御**：1帧（双臂交叉）
- **受击**：2帧（后退、恢复）
- **胜利**：4帧循环（高举双臂庆祝）

## 5. 音效设计（基础方案）

- **背景音乐**：简单的8-bit电子风格战斗音乐（预留接口）
- **攻击音效**：像素风格的"砰"和"嗖"声
- **受击音效**：金属撞击声
- **胜利音效**：8-bit胜利旋律

## 6. 性能要求

- 60帧每秒流畅运行
- 纯前端实现，无需服务器
- 响应式布局，支持不同屏幕尺寸
- 键盘事件无冲突

## 7. 技术实现约束

- 使用HTML5 Canvas进行渲染
- 原生JavaScript实现，无外部游戏引擎依赖
- CSS3用于UI界面和特效
- 使用requestAnimationFrame实现游戏循环
