# 01 · 选股标准（三层漏斗）

> 中线趋势交易的选股，必须**自上而下**：先看天（市场环境），再看地（主线板块），最后看人（前排个股）。
> 顺序不能颠倒。大多数人亏损的原因，是直接从"个股"这一步开始，跳过了前两层。

---

## 第一层：市场环境（决定"要不要做 / 做多重"）

**这一步决定总仓位开关，比选哪只票重要 10 倍。**

### 判断方法（用宽基指数，建议参考沪深300 / 中证500 / 创业板指）

| 市场状态 | 特征 | 对应总仓位 |
|---|---|---|
| **进攻** | 指数在中期均线上方运行，量能温和放大，主线清晰、赚钱效应好 | 可到上限（如 80%–100%） |
| **中性/震荡** | 指数在均线附近反复，量能萎缩，板块快速轮动、持续性差 | 半仓以下（≤ 50%） |
| **防守** | 指数跌破中期均线，放量下跌，普跌、题材熄火 | 低仓或空仓（≤ 20% 或 0） |

### 可量化的简化规则（默认值，可调）

- 以**沪深300 的 60 日均线**作为牛熊分界参考：
  - 指数在其上方且 60 日均线走平/上翘 → **进攻或中性**；
  - 指数跌破且 60 日均线走平/下弯 → **防守**。
- 辅助观察：成交量（较前期是否放大/萎缩）、涨跌家数比、涨停/跌停家数、板块轮动速度（轮动越快说明越难做）。

### 铁律

> **市场环境是防守状态时，禁止开新仓（除非体系明确允许的极低仓试探）。**
> 环境不好时"少亏"就是"赚"。

## 第二层：主线板块（决定"钱在哪"）

**中线趋势要押"当前主线"，而不是随便找个跌得多的板块抄底。**

### 什么是"主线"？

满足以下多条特征的板块，才算当前主线：

1. **资金持续流入**：板块成交额 / 换手率连续多日、多周排在市场前列；
2. **趋势向上**：板块指数创阶段新高或强势运行，回踩不破中期均线；
3. **有催化/逻辑**：政策支持、行业景气上行、业绩爆发、重大事件驱动；
4. **有龙头带动**：板块内出现持续走强、带动人气的标杆个股。

### 板块分类与参与原则

| 类型 | 举例方向 | 参与原则 |
|---|---|---|
| **进攻型主线** | 高景气成长、强题材 | 趋势确认后参与，不参与情绪末端 |
| **防御型主线** | 红利、公用事业、部分消费 | 市场弱势时作为避风港，仓位偏低 |

### 铁律

- **只参与"已有明确趋势且尚未过度炒作"的板块。**
  - 刚启动 → 等放量突破确认再进；
  - 趋势中段 → 主战场，重点参与；
  - **已翻倍 / 连续加速 / 分歧巨大 → 减少或放弃参与。**
- **同一时间聚焦 1–3 个主线板块**，不要什么板块都想掺一脚。
- 板块逻辑要能**一句话说清**（如"AI 算力资本开支上行"），说不清说明你没看懂，别买。

## 第三层：个股（在主线中选"前排"）

**在选对的板块里，只做前排，不做后排补涨。**

### 3.1 前排的标准（满足越多越好）

- **强度领先**：板块内涨幅、成交额领先，或启动最早、回调最抗跌；
- **人气标杆**：是板块的"风向标"，它涨板块就活跃，它跌板块就退潮；
- **量价配合**：上涨放量、回调缩量，量能健康；
- **技术形态**：均线多头排列（如 5 > 10 > 20 > 60 日均线向上），价格站稳关键平台/前高上方。

> 一句话：**宁可买板块第一，不买板块第五。**

### 3.2 基本面筛选（中线必须看，区别于超短）

- 营收与净利润**增速趋势向上**（至少不是持续下滑）；
- 行业处于景气周期，或逻辑清晰可验证；
- 行业地位稳固（细分龙头、竞争格局好）；
- 估值不离谱（结合行业和成长性判断，回避纯题材泡沫）；
- 市值适中（回避流动性极差的小票；成长弹性偏好则偏中小市值）。

### 3.3 技术面筛选（买点前置条件）

- 处于上升趋势中，**不买下跌趋势里的"便宜货"**；
- 价格站上关键均线群，且均线向上发散；
- 有清晰的**支撑位**（前平台、颈线、关键均线）可用作止损参考。

### 3.4 一票否决（排除项，命中任一即剔除）

- ST / *ST、退市风险警示；
- 短期大额**限售解禁**、大股东**大额减持**；
- 高股权质押、商誉减值风险、财务造假嫌疑；
- 业绩大幅预亏 / 爆雷风险；
- 连续涨停后的**高位巨量**（情绪末端接盘风险）；
- 流动性极差（成交额过低）的票。

## 三层漏斗的"一页版"速查

```
① 市场环境：进攻？中性？防守？   → 决定总仓位（不做 = 也是一种正确决定）
② 主线板块：钱在哪个板块？逻辑是什么？ → 只做 1–3 个，说清逻辑
③ 前排个股：板块第一，不买第五    → 基本面 + 技术面 + 排除项过筛
        ↓
   进入"股票池"，等待买点（见文档 02）
```

## 常见误区（对照自查）

| 误区 | 纠正 |
|---|---|
| 看个股涨得好就买，不看看它在什么板块 | 先板块后个股，板块不对个股再好也难持续 |
| 专挑跌得多的"便宜货" | 中线做趋势，不做抄底，跌得多≠便宜 |
| 板块里买了一只"补涨"的后排 | 只做前排/龙头，后排补涨持续性差 |
| 同时持有十几个板块的票 | 聚焦 1–3 个主线，分散不等于乱撒网 |
| 市场明显走弱还在频繁开仓 | 环境是总开关，防守状态以少亏为赢 |
