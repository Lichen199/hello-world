# 04 · 执行清单与模板

> 把规则变成习惯的工具箱。**打印或复制到表格软件里长期使用。**
> 智能体（Skill）会引导你逐条填写这些内容。

---

## 一、交易前检查清单（下单前必须逐条过）

**任何一条不过，就不下单。**

- [ ] **1. 市场环境**：现在是进攻 / 中性 / 防守？总仓位档位是？
- [ ] **2. 板块**：标的属于当前主线板块吗？逻辑能否一句话说清？
- [ ] **3. 位置**：标的是板块前排/龙头吗？（不是 → 否决）
- [ ] **4. 排除项**：是否命中 ST / 解禁 / 减持 / 爆雷 / 高位巨量等一票否决？
- [ ] **5. 买点**：属于突破买点还是回调买点？（都不是 → 否决）是否追高？（追高 → 否决）
- [ ] **6. 止损价**：买入依据被破坏的位置在哪？止损价定好了吗？
- [ ] **7. 仓位**：用"单笔风险法"算出数量了吗？是否超单票/单板块上限？
- [ ] **8. 目标与盈亏比**：目标位在哪？盈亏比是否 ≥ 2:1？
- [ ] **9. 证伪条件**：什么信号出现说明我错了？到时怎么处理？
- [ ] **10. 情绪**：现在有没有冲动/贪婪/恐惧？是不是在"手痒"？（有 → 暂停）

## 九、一页版日常流程

```
盘前：市场环境判断 → 更新总仓位档位 → 检查持仓动作 → 检查股票池买点
盘中：只执行盘前定好的计划，不临时起意
盘后：填《每日复盘表》→ 更新《持仓跟踪表》《股票池表》
周末：填《周度复盘表》→ 找 Top1 错误 → 记入《经验库》
月底：体系有效性检视 → 调参数
```
