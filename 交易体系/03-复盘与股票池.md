# 03 · 复盘与股票池

> 这一篇解决你的**"缺乏复盘与纪律"**。
> 复盘不是记流水账，而是**"把每一笔交易的教训，变成下一条规则"**。
> 股票池是你**"个人经验与机会的沉淀池"**——积累各板块前排公司与核心逻辑。

---

## 一、复盘的目的

| 目标 | 具体含义 |
|---|---|
| 提高**执行率** | 对照"计划"和"实际操作"，看偏差在哪、为什么 |
| 归因**错误类型** | 找出最费钱的错误，针对性约束 |
| 沉淀**经验** | 把有效的判断和失败的教训写成可复用的规则 |
| 校验**体系** | 统计胜率/盈亏比，判断体系是否有效、参数是否要调 |

> **衡量进步的指标不是"赚了多少"，而是"错误类型是否在收敛"。**

---

## 二、三层复盘节奏

### 2.1 每日复盘（10–20 分钟，收盘后）

固定回答以下问题（可直接用文档 04 的《每日复盘表》）：

1. **市场环境**：指数在均线上/下？量能？进攻/中性/防守？→ 明天总仓位结论。
2. **主线板块**：今天强势板块是哪些？逻辑是什么？和昨天比有无切换？
3. **股票池**：池中个股今天表现如何？有无买点/卖点/需剔除的？
4. **持仓**：每只票是否触及止损/止盈/逻辑破坏信号？明天动作是什么？
5. **今日交易**（若有）：是否符合计划？执行偏差在哪？
6. **情绪记录**：今天有没有冲动、贪婪、恐惧、懊悔？触发点是什么？

### 2.2 每周复盘（30–60 分钟）

统计与归因：

- **三个核心指标**：本周胜率、平均盈亏比、**执行率**（按规则操作的比例）；
- **错误归因**：把本周所有亏损/失误归类（如"追高""不止损""无计划交易""板块选错"），统计出现次数；
- **找出 Top1 错误** → 下周针对它加一条约束；
- **规则检视**：有没有哪条规则反复被违反？是规则不合理，还是你做不到？

### 2.3 每月检视

- 统计整月：收益率、最大回撤、胜率、盈亏比、执行率；
- **体系有效性判断**：
  - 执行率高但收益差 → 可能是选股/买卖点规则需要优化；
  - 收益差且执行率低 → 是**纪律问题**，先解决执行，别急着改规则；
- **参数调整**：单笔风险 r、单票上限、总仓位档位是否需要微调；
- 把本月结论写入智能体的"**个人经验库 / 规则迭代记录**"。

---

## 三、错误归因分类表（复盘时对照归类）

每一次亏损/失误，都归入以下某一类（这是做"错误收敛"的基础）：

| 错误类型 | 典型表现 |
|---|---|
| 无计划交易 | 盘中临时起意买入，没有计划价/止损位 |
| 追高 | 在情绪高潮/连续大涨后买入 |
| 不止损 | 触及止损位没卖，或根本没有止损 |
| 亏了加仓 | 向下摊平成本 |
| 过早止盈 | 趋势还没走完就跑了（赚小钱） |
| 板块选错 | 买了非主线/已退潮的板块 |
| 选了后排 | 在板块里买了补涨/跟风股 |
| 仓位失控 | 单票/单板块超限，或满仓 |
| 情绪化 | 恐惧割在底部、贪婪追在高位 |
| 逻辑破坏未离场 | 中线票逻辑已证伪仍不走 |

> **每周只针对出现次数最多的 1 类错误做改进。一次改一个，才能改得动。**

## 四、股票池管理（沉淀板块前排公司 + 逻辑）

股票池是中线交易者的**核心资产**：不是"随便加自选"，而是**结构化地记录每个板块的前排公司与逻辑**。

### 4.1 股票池的组织方式

按**板块/主线**分组，每个板块记录：

- **板块名 + 当前状态**（主线 / 观察 / 退潮 / 淘汰）；
- **板块逻辑**（一句话，可验证）；
- **前排公司清单**（每只记录：角色=龙头/前排/跟风、核心逻辑、关键价位、当前状态）。

### 4.2 每只票要记录什么（见文档 04《股票池表》）

| 字段 | 说明 |
|---|---|
| 股票 / 代码 | 标的 |
| 所属板块 | 用于板块集中度控制 |
| 板块角色 | 龙头 / 前排 / 跟风 |
| 核心逻辑 | 一句话逻辑，可证伪 |
| 买点类型 | 突破 / 回调 / 未到买点 |
| 关键价位 | 支撑 / 压力 / 计划止损 |
| 状态 | 关注 / 等待买点 / 持有 / 减仓 / 淘汰 |
| 加入日期 / 备注 | 便于回顾逻辑演变 |

### 4.3 股票池的维护规则

- **进池**：属于主线板块 + 是前排 + 逻辑清晰 + 过排除项 → 进池观察；
- **升级**：出现买点 → 从"关注"升级为"持有"；
- **降级/淘汰**：板块退潮、逻辑被证伪、变成后排 → 移出并记录原因；
- **定期清理**：每周清理一次，**只留还有逻辑的票**，池子不超过可控数量（如 30–50 只）。

> **股票池的价值 = 把"临时找票"变成"提前准备"。**
> 买点出现时你才不会手忙脚乱、临时决策、追涨杀跌。

### 4.4 板块经验沉淀（长期复利）

为每个常做的板块，逐步积累一份"**板块档案**"：

- 这个板块的**驱动逻辑**是什么（政策/景气/事件）；
- **前排公司**有哪些、各自卡位是什么；
- 历史上它是**怎么启动、怎么退潮**的（规律）；
- 下次出现类似催化时，**该看哪些信号**。

> 时间久了，你对几个熟悉板块的理解会远超常人——这就是中线交易者的护城河。

---

## 五、复盘闭环（把教训变成规则）

```
记录交易 → 归类错误 → 找 Top1 错误 → 新增/修改一条规则
       → 写入"个人经验库" → 下周执行新规则 → 再复盘验证
```

**是否形成闭环，是"系统交易者"和"凭感觉交易者"的分水岭。**

---

## 六、常见误区

| 误区 | 纠正 |
|---|---|
| 只记盈亏，不记过程和情绪 | 复盘要记录"为什么这么决策"，不是"赚亏多少" |
| 复盘时只找借口（"大盘不好"） | 归因要落到**可控项**：我哪里没按规则做 |
| 一次想改一堆毛病 | 每周只改 Top1 错误 |
| 股票池就是随便加自选 | 结构化记录板块角色、逻辑、状态 |
| 池子几百只票 | 清理，只留有逻辑的，保持可控 |
