# 02 · 买卖点 · 仓位 · 风控

> 这一篇解决你的**"仓位与风控混乱"**。核心思想：**先定亏多少，再定买多少。**
> 所有参数给的是**默认建议值**，你可以在实战中调整，并记录到智能体的"个人参数"里。

---

## 一、买点：只有两类，都要求"不追高"

> 中线交易**禁止追高**（禁止在连续大涨、涨停打开、情绪高潮时买入）。

### 买点 A｜突破买点

- **形态**：放量突破前期高点 / 平台 / 颈线 / 箱体上沿；
- **确认**：**板块同步走强**（不是个股孤立突破），收盘站稳突破位上方；
- **含义**：趋势从"蓄势"进入"展开"，是中线趋势最经典的启动点。

### 买点 B｜回调买点（低吸）

- **形态**：上升趋势中回踩关键均线（如 10 / 20 日均线）或前平台支撑；
- **确认**：**缩量止跌**，随后重新转强（放量收复短均线）；
- **含义**：趋势中段的二次上车机会，风险收益比更优。

### 建仓方式：分批（禁止一次满仓）

- **第一批（试仓）**：计划仓位的 **50%**，在买点出现时买入；
- **第二批（确认加仓）**：趋势继续走强 / 突破确认后，加剩余 **50%**；
- **铁律：只在盈利时加仓，亏损绝不加仓（不加仓摊平成本）。**

## 二、卖点：三套规则，对应三种情形

> 卖出比买入更重要。**亏损的人多半是"该卖不卖"。** 卖出必须事先定好，不能临场拍脑袋。

### 卖点 1｜止损卖（纪律，无条件执行）

- 触发条件（满足任一）：
  - 价格跌破**买入依据**（突破位/平台/关键均线）；
  - 触及事先设定的**止损价**；
  - 持股超过预期周期仍未走出趋势（时间止损，如 1–2 个月）。
- **执行要求**：**无条件、立刻、不找理由。** 止损是体系的成本，不是失败。

### 卖点 2｜止盈 / 减仓卖（趋势派做法）

- 达到目标涨幅后**分批止盈**（如 +20% 减一半，剩余用移动止盈保护）；
- 出现**见顶信号**时减仓：放量滞涨、长上影线、跌破短期均线、板块退潮、龙头走弱；
- **移动止盈**：随股价上移，把止损位上移到成本上方，锁定利润。

### 卖点 3｜逻辑卖（中线特有，最重要）

- 买入时的**核心逻辑被破坏** → 无条件离场，不看盈亏：
  - 业绩被证伪 / 暴雷；
  - 政策转向、行业景气拐点向下；
  - 板块主线切换（资金已经离开这个方向）。
- 中线持仓的信仰来自**逻辑**，逻辑没了，股票就没理由拿着。

> **优先级：逻辑卖 = 止损卖 > 止盈卖。** 前者是保命，后者是兑现。

## 三、仓位管理（用"单笔风险法"算仓位）

### 3.1 核心公式

```
单笔最大亏损金额 = 账户净值 × 单笔风险百分比 r%
计划买入数量     = 单笔最大亏损金额 ÷ (买入价 − 止损价)
仓位金额         = 计划买入数量 × 买入价
```

### 3.2 计算示例（示意，非真实交易）

| 项目 | 数值 |
|---|---|
| 账户净值 | 100 万 |
| 单笔风险 r | 1%（= 1 万） |
| 计划买入价 | 10.00 元 |
| 止损价 | 9.00 元（止损幅度 10%） |
| 每股风险 | 1.00 元 |
| 可买数量 | 1 万 ÷ 1.00 = 10,000 股 |
| 实际仓位 | 10,000 × 10 = 10 万元（占总仓 10%） |

**含义：** 止损幅度越大，仓位必须越小。**止损位越近，越能买多；止损位越远，越要买少。**

### 3.3 仓位分层参数（默认建议值，可调）

| 参数 | 默认建议值 | 说明 |
|---|---|---|
| 单笔风险 r | 1%–2% | 每笔交易可承受的账户亏损 |
| 单票最大仓位 | ≤ 20% | 集中度上限 |
| 同时持仓数量 | 5–8 只 | 太少不分散，太多管不过来 |
| 板块集中度 | 单一板块 ≤ 40% | 防止板块级风险全砸 |
| 总仓位 | 由市场环境决定（见文档 01） | 0 / 50% / 100% 三档 |

## 四、风控铁律（不可违反）

1. **每笔交易必须有止损**，无止损不下单。
2. **只用闲钱**，不用杠杆、不融资（中线尤其要扛得住波动）。
3. **亏损绝不加仓**（禁止摊平成本）。
4. **不满仓单票**，单票不超过上限。
5. **组合回撤纪律**：
   - 账户回撤达 **10%** → 总仓位**砍半**，只做最确定的机会；
   - 账户回撤达 **15%** → **停手 3–5 天**，全面复盘后再小仓恢复；
   - 连亏 **3 笔** → 强制降仓 + 复盘（大概率是市场环境或体系执行出了问题）。
6. **不参与不熟悉、看不懂逻辑的品种。**
7. **每天开盘前想清楚：今天如果触发止损/止盈，我卖不卖？** 事先决定，避免临场情绪。

---

## 五、一页版执行顺序

```
1. 市场环境 → 总仓位档位（0 / 50% / 100%）
2. 标的属于主线板块？是前排？
3. 买点类型（突破 / 回调），不追高
4. 定止损价 → 用公式算出仓位 → 分批建仓
5. 持仓中：盯止损 / 止盈 / 逻辑是否破坏
6. 卖出后：进复盘流程（文档 03）
```

## 六、常见误区（对照自查）

| 误区 | 纠正 |
|---|---|
| 先想买多少，再随意定个止损 | 反了。先定止损价，再算仓位 |
| 止损位设得很远，为了"扛得住" | 止损位越远，仓位必须越小，否则单笔风险超标 |
| 亏了舍不得割，还加仓摊平 | 严禁。加仓只在盈利时 |
| 赚一点就跑，亏了死扛 | 这是"截断利润、放任亏损"，长期必亏 |
| 满仓一只票赌爆发 | 单票上限，永不满仓单票 |
| 连亏了想"翻本"加大仓位 | 连亏是降仓信号，不是加仓信号 |
