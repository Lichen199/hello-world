# 02 · 买卖点 · 仓位 · 风控

> 核心思想：**先定亏多少，再定买多少。** 本篇把"买点 / 卖点 / 止损"落成**可量化、可执行的标准**。
> 文中数值是**默认建议值**；你实战迭代出的最终版，沉淀在 `我的档案/买卖点与止损标准.md`，**以那份为准**。

---

## 一、买入点标准（两类，均"不追高"）

> **通用前提（三条同时满足才允许买）**：① 市场环境允许开仓；② 标的属当前主线板块且是前排；③ 不在追高位置。

### 买点 A｜突破买点

| 条件 | 标准（默认建议值） | 性质 |
|---|---|---|
| 突破位 | 放量突破前高 / 平台 / 颈线 / 箱体上沿 | 必备 |
| 量能 | 当日成交额 ≥ 近 5 日均量 × 1.5 | 必备 |
| 收盘确认 | 收盘站稳突破位上方（≥ 突破位 +1%） | 必备 |
| 板块同步 | 所属板块指数同步走强（当日跑赢大盘） | 必备 |
| 均线 | 5 > 10 > 20 日均线多头排列 | 加分 |
| 位置 | 距近期低点涨幅 < 30%（未过度透支） | 否决项 |

### 买点 B｜回调买点（低吸）

| 条件 | 标准（默认建议值） | 性质 |
|---|---|---|
| 回踩位 | 回踩 10 日或 20 日均线 / 前平台支撑 | 必备 |
| 缩量 | 回踩时成交额 ≤ 近 5 日均量 × 0.8 | 必备 |
| 止跌 | 出现止跌 K 线（十字星/长下影/小阳）或放量收复 5 日线 | 必备 |
| 不破位 | 未有效跌破关键支撑（平台/颈线） | 必备 |
| 趋势 | 中期均线（20/60 日）仍向上 | 加分 |

### 统一否决条件（任一命中即不买）

- **追高**：连续大涨后、涨停打开后、板块情绪高潮时；
- **不在主线**：板块已退潮，或标的非板块前排；
- **命中排除项**：ST、解禁、减持、爆雷、高位巨量等；
- **算不清**：止损位不明确，或盈亏比 < 2:1。

### 建仓方式：分两批

- **试仓 50%**（买点确认时）→ **加仓 50%**（趋势走强确认后）；
- **铁律：只在盈利时加仓，亏损绝不加仓（不摊平）。**

## 二、卖出标准（三类，按优先级）

> 卖出必须**事先写定**，不能临场拍脑袋。优先级：**逻辑卖 = 止损卖 > 止盈卖**。

### 卖点 1｜止损卖（纪律，无条件执行）

触发（满足任一）：
- 跌破**买入依据**（突破位/平台/关键均线）；
- 触及事先设定的**止损价**（见第三节）；
- **时间止损**：默认持有 20 个交易日仍未创新高且跌破 20 日线。

### 卖点 2｜止盈 / 减仓卖

量化分批止盈（默认建议值）：
- **+15% 减 1/3**；**+25% 再减 1/3**；剩余 1/3 用**移动止损**（见第三节 D）保护。

见顶信号（出现即减仓）：放量滞涨 / 长上影线、跌破 10 日线、板块退潮、龙头走弱。

### 卖点 3｜逻辑卖（中线核心，最重要）

**买入逻辑被证伪 → 无条件离场，不看盈亏**：
- 业绩被证伪 / 暴雷；
- 政策转向、行业景气拐点向下；
- 板块主线切换（资金已离开该方向）。

## 三、止损标准（四选一，计划时先选定）

> 每笔交易在《交易计划表》里必须注明用**哪一种止损**，不得临场决定。

| 方法 | 规则 | 适用 |
|---|---|---|
| **A 技术位止损（默认）** | 止损价 = 买入依据下方（突破位/平台/关键均线下方 1–2%）；止损幅度一般 ≤ 8%–10% | 有清晰结构支撑的票 |
| **B 固定金额止损** | 单笔亏损 = 账户净值 × r%（默认 1%），与仓位公式联动 | 通用，配合仓位算法 |
| **C 时间止损** | 买入后默认 20 个交易日未创新高且跌破 20 日线 → 离场 | 逻辑迟迟不兑现 |
| **D 移动止损** | 盈利后把止损上移至成本价（保本），再逐步上移至前低/关键均线 | 已有浮盈，保护利润 |

**选择规则（默认）**：有明确技术支撑 → 用 **A**；结构松散 → 用 **B**；全程叠加 **D** 保护浮盈；逻辑类持仓再叠加 **C**。

**止损纪律**：触及即执行——**无条件、不找理由、不因"再等等"而下移**。止损是体系的成本，不是失败。

## 四、仓位管理（用"单笔风险法"算仓位）

### 4.1 核心公式

```
单笔最大亏损金额 = 账户净值 × 单笔风险百分比 r%
计划买入数量     = 单笔最大亏损金额 ÷ (买入价 − 止损价)
仓位金额         = 计划买入数量 × 买入价
```

### 4.2 计算示例（示意，非真实交易）

| 项目 | 数值 |
|---|---|
| 账户净值 | 100 万 |
| 单笔风险 r | 1%（= 1 万） |
| 计划买入价 | 10.00 元 |
| 止损价 | 9.00 元（止损幅度 10%） |
| 每股风险 | 1.00 元 |
| 可买数量 | 1 万 ÷ 1.00 = 10,000 股 |
| 实际仓位 | 10,000 × 10 = 10 万元（占总仓 10%） |

**含义：** 止损幅度越大，仓位必须越小。**止损位越近越能买多；止损位越远越要买少。**

### 4.3 仓位分层参数（默认建议值，可调）

| 参数 | 默认建议值 | 说明 |
|---|---|---|
| 单笔风险 r | 1%–2% | 每笔交易可承受的账户亏损 |
| 单票最大仓位 | ≤ 20% | 集中度上限 |
| 同时持仓数量 | 5–8 只 | 太少不分散，太多管不过来 |
| 板块集中度 | 单一板块 ≤ 40% | 防止板块级风险全砸 |
| 总仓位 | 由市场环境决定（见文档 01） | 0 / 50% / 100% 三档 |

## 五、风控铁律（不可违反）

1. **每笔交易必须有止损**，无止损不下单。
2. **只用闲钱**，不用杠杆、不融资（中线尤其要扛得住波动）。
3. **亏损绝不加仓**（禁止摊平成本）。
4. **不满仓单票**，单票不超过上限。
5. **组合回撤纪律**：
   - 账户回撤达 **10%** → 总仓位**砍半**，只做最确定的机会；
   - 账户回撤达 **15%** → **停手 3–5 天**，全面复盘后再小仓恢复；
   - 连亏 **3 笔** → 强制降仓 + 复盘。
6. **不参与不熟悉、看不懂逻辑的品种。**
7. **每天开盘前想清楚：今天若触发止损/止盈，我卖不卖？** 事先决定，避免临场情绪。

## 六、一页版执行顺序

```
1. 市场环境 → 总仓位档位（0 / 50% / 100%）
2. 标的属于主线板块？是前排？
3. 买点类型（突破 A / 回调 B），逐条对照量化标准，不追高
4. 选定止损方法（A/B/C/D）→ 定止损价 → 用公式算仓位 → 分批建仓
5. 持仓中：盯止损 / 止盈分批 / 逻辑是否破坏
6. 卖出后：进复盘（文档 03），并把新的买/卖/止损认识沉淀到档案
```

## 七、常见误区（对照自查）

| 误区 | 纠正 |
|---|---|
| 先想买多少，再随意定个止损 | 反了。先定止损价，再算仓位 |
| 止损位设得很远，为了"扛得住" | 止损位越远，仓位必须越小，否则单笔风险超标 |
| 亏了舍不得割，还加仓摊平 | 严禁。加仓只在盈利时 |
| 赚一点就跑，亏了死扛 | 这是"截断利润、放任亏损"，长期必亏 |
| 满仓一只票赌爆发 | 单票上限，永不满仓单票 |
| 连亏了想"翻本"加大仓位 | 连亏是降仓信号，不是加仓信号 |
| 买卖点每次都重新想 | 用固定标准 + 逐步迭代，别每次从零拍脑袋 |

## 八、本篇标准如何"逐步沉淀"

本篇给的是**基线标准**。你要做的是让它**越用越贴合你**：

```
① 按基线标准执行每一笔
        ↓
② 每笔交易/每周复盘后，问三个问题：
   - 这次的买入点，标准里覆盖到了吗？漏了什么？
   - 卖出/止损，是按标准执行的吗？标准够明确吗？
   - 有没有"标准之外但效果更好"的做法？
        ↓
③ 有新认识 → 在 `我的档案/买卖点与止损标准.md` 里
   新增或修订对应条款，并在"迭代记录"里记一行（含日期、来源、修改内容）
        ↓
④ 修正后的标准，下一笔就按它执行
```

> **原则：标准只"长"不"翻"。** 一次只改一两条，并保留旧版本记录，
> 避免频繁推翻导致标准失效。**智能体负责引导这个沉淀过程并落盘。**
