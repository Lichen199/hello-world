# E1 · 每日检查清单（止血阶段）

> 目标：**不再制造新亏损。** 本阶段不看盈亏，只看"是否按规则做"。
> 用法：**盘前 3 分钟 → 盘中只记录不操作 → 盘后 5 分钟**。每天照着打勾即可。
> 验收：**连续 10 个交易日，0 次亏损加仓、0 次破位未执行。**

---

## 一、E1 三条硬规则（背下来）

1. **止损全部预设条件单**——破位自动成交，**不许撤单、不许改价、不许下移**。
2. **亏损状态零加仓**——不给自己"摊低成本"这个选项，**无条件、无例外**。
3. **仓位 ≤ 50%**——当前 48.57%，**只允许减，不允许加**。

---

## 二、盘前清单（开盘前 3 分钟）

| ☐ | 检查项 | 标准 |
|---|---|---|
| ☐ | **四张条件单是否有效** | 长江 28.62（400）／平安 11.45（900）／创业板 2.40（4,300）／纳指 2.56（700） |
| ☐ | 条件单是否被误撤 / 已过期 | 全部显示"已委托 / 有效" |
| ☐ | 今日是否有买入打算 | **有 → 必须先填《交易计划表》（止损价＋仓位＋证伪条件）；填不出 → 不许下单** |
| ☐ | 当前仓位是否 ≤50% | 是 → 今日**无任何加仓空间** |

---

## 三、盘中清单（只记录，不操作）

| ☐ | 检查项 | 标准 |
|---|---|---|
| ☐ | 有没有"临时起意"想买 / 想加 | 写进下方"冲动记录"，**记录 ≠ 执行** |
| ☐ | 创业板（亏损仓）有无任何买入 | **必须为 0** |
| ☐ | 条件单触发后是否手动干预 | **不许撤单、不许改价**，只看成交回报 |
| ☐ | 唯一允许的主动动作 | 创业板 **≥2.65 分批减至 2,000 份内**（减仓合规，加仓违规） |

---

## 四、盘后清单（收盘后 5 分钟）

| ☐ | 检查项 | 标准 |
|---|---|---|
| ☐ | 更新持仓跟踪 | 数量 / 现价 / 浮亏 / 条件单状态 |
| ☐ | 当日有无违规 | 有=1，无=0（填进下表） |
| ☐ | 情绪一句话 | 例："看到创业板涨想加仓，忍住了" |
| ☐ | 打过程分 | 见第五节，5 项各 20 分 |

---

## 五、过程分（每日一算，与盈亏无关）

| 记分项 | 得分条件 | 分 |
|---|---|---|
| ① 有书面计划（含止损价） | 有=20；无交易=20（默认）；临时起意=0 | 20 |
| ② 止损预设且未撤改 | 是=20；否=0 | 20 |
| ③ 未在亏损状态加仓 | 未违反=20；违反=0 | 20 |
| ④ 仓位 ≤50% | 是=20；否=0 | 20 |
| ⑤ 当日全部为计划内交易 | 是=20；临时起意=0 | 20 |

> **赚了但违规 = 0 分；亏了但守规 = 100 分。**

## 七、违规处理（事前定死，不临场商量）

| 情形 | 处理 |
|---|---|
| 当日出现 1 次违规 | **当日立即停止所有操作**，次日只允许减仓 |
| 10 日内累计 2 次违规 | **本周禁止开任何新仓**，并写一份违规复盘 |
| 条件单被自己撤改 | 视为违规，与上面同等处理 |
